I want a python script that compares two files and shows the differences between them.

i want a layered-based architecture
this shall be the layers:
1. read files;
    if the one or both files doesent exist, or have different encodings, then the script shall end.
    export: this should generate a csv and txt file with the names of the files and the econdings.
    report: this generates a pdf file showing the files readed with names and econdings and if the process was successful or not.

2. compare columns
    if the columns are different, then the script shall end.
    export: this should generate a csv and txt file with the differences between the columns.
    report: this generates a pdf file showing the columns readed with names and econdings and if the process was successful or not.
        this should also show the differences between columns, the columns that left has but the other one doesnt, and the columns that left doesnt but the other one has.
        this should also check the datatypes of the columns.
    the script shall continue with the common columns ( this should also be in the pdf file )

3. compare rows
    if the rows are different by id, then the script shall end.
    this should also check for duplicates
    export: this should generate a csv and txt file with the differences between the rows.
    report: this generates a pdf file showing the rows readed with names and econdings and if the process was successful or not.
        the pdf should display a horizontal rectangle bar graph showing the number of left, inner and right rows, and the number of duplicates

4. value comparison
    here we compare the actual values of each cell
    if the values are different, then the script shall end.
    export: this should generate a csv file with the differences between the values.
    report: this generates a pdf file showing the value differences and if the process was successful or not.
        this should feature a vertical graph showing the columns names and the count of differences on a horizontal bar graph.
